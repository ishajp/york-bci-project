# preprocessing
This code is used to clean the data post-acquisition and prepare it for the next step, which is passing the data through feature extraction and classification pipelines.
Cleaning involves resampling the data, checking it for bad channels, montaging and re-referencing, filtering, and then fitting ICA on it to remove artifacts. Finally, in order to prepare it for the decoding pipeline, we identify relevant events and use them to epoch the data and baseline correct it. We create 2 kinds of epochs: one for Time-frequency analyses and power change, and the other to feed into the decoding algorithms.
