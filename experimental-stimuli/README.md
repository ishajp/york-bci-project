# experimental-stimuli
This experimental task was administered to participants during the data collection phase and was implemented using PsychoPy. The experiment was accompanied by a .csv file containing the output stimuli, including text-based movement commands for six motor imagery classes and supplementary video demos used to standardise task performance. These served as motor imagery cues targeting right-arm movements.
The paradigm followed an event-related design organised into blocks, with each block consisting of five repetitions of six right-arm movement classes, resulting in six blocks in total across the experiment.
Each trial had a duration of 13 seconds with a jittered inter-trial interval (ITI). The trial structure consisted of a 2-second baseline period, followed by the presentation of a movement cue at t = 0 and a corresponding movement video at t = 2. This delay was introduced to allow sufficient time for task comprehension prior to motor imagery execution. The motor imagery period continued until t = 10, followed by a post-stimulus rest period until t = 13.
